# 📊 Market Data Service

## 🧬 Architecture
* **Frontend:** SpringDoc OpenAPI
* **Backend:** Spring Boot 4.1.2

## 🔧 Prerequisites
* `JDK 25+`
* `Maven 3.x`

## 📐 Project Structure
```
market-data-service/
└── src/
    └── main/
        └── java/
            └── com/
                └── josef/
                    └── marketdataservice/
                        └── MarketDataService.java
```

## 🚀 Getting Started
1. Run `MarketDataService.java`
2. Open **http://localhost:8080/swagger-ui/index.html**
